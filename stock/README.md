# Склад в Google Таблице — подключение за 5 минут

Остатки по каждой позиции (товар × размер × цвет) живут в обычной Google Таблице. Её можно править с телефона, сайт подхватывает изменения в течение ~2 минут, а при заказе остаток списывается сам.

## 1. Создать таблицу
1. В папке `shop` выполнить `npm run stock:export` — появится `shop/stock.csv` со всеми позициями.
2. Создать новую Google Таблицу → **Файл → Импорт → Загрузить** `stock.csv` → «Заменить текущий лист».
3. Переименовать лист в **`stock`** (строчными буквами). Колонки: `sku | товар | размер | цвет | остаток`.
4. Лист `log` создастся сам при первом заказе.

> Колонку `sku` не меняйте — по ней сайт находит позицию. Править можно только `остаток`.

## 2. Подключить скрипт
1. В таблице: **Расширения → Apps Script**.
2. Вставить код из `stock/apps-script.gs`, в строке `KEY` вписать длинный секрет (например, 30 случайных букв и цифр).
3. **Развернуть → Новое развёртывание → Тип: Веб-приложение**
   - Выполнять от имени: **Я**
   - У кого есть доступ: **Все**
4. Разрешить доступ → скопировать **URL веб-приложения** (`https://script.google.com/macros/s/…/exec`).

## 3. Указать на сайте
Боевой сайт статичный (Timeweb), остатки он читает прямо из браузера:
в `shop/src/lib/site.ts` → `stockUrl: 'https://script.google.com/macros/s/…/exec'` → `bash deploy/publish-site.sh`.

## 4. Вход продавца на сайте
Открыть https://nosinoski.ru/admin → ввести тот же секрет, что в `KEY`. Телефон запомнит ключ.
После этого в каждой карточке товара под кнопкой «В корзину» — панель **«Склад»**: остаток по каждому цвету/размеру, кнопки − / +, «Сохранить в таблицу».
Каждая правка пишется строкой в лист `log` («правка с сайта»). Покупатели панель не видят.

## Как это работает
- Сайт показывает остатки из таблицы (кэш 2 мин). Размер с нулём — зачёркнут.
- При заказе сайт проверяет остаток «вживую» и списывает его под блокировкой — последнюю пару не купят дважды.
- Каждый заказ пишется в лист `log` (дата, номер заказа, sku, кол-во, остаток после).
- Если остаток стал ≤ 1 — в Telegram приходит «⚠️ Заканчивается».
- Пришла новая партия — просто увеличьте число в колонке `остаток`.
- Добавили новый товар в `products.json` — снова `npm run stock:export` и допишите новые строки в таблицу.

Если таблица не подключена, сайт берёт остатки из `products.json` (поле `stock` у каждой позиции) и ничего не списывает.
