# 7. Деньги и доставка — пилот без ИП

> Ира сейчас работает в найме, ИП нет. Ниже — как запустить пилот: Новосибирск + Авито для других городов. Это не юридическая консультация.

## Честно про статус

- **Самозанятость не подходит для перепродажи.** Самозанятые (НПД, закон 422-ФЗ) продают только то, что сделали сами. Если носки закупаются у поставщика и продаются с наценкой, нужно **ИП** (УСН 6%). Если оформить самозанятость и перепродавать, налоговая может снять статус и доначислить 13% НДФЛ.
- **Пилот как частное лицо** (Авито + встречи в городе) — серая зона: регулярная перепродажа с наценкой по закону считается предпринимательством. На небольших объёмах это обычная практика Авито, но, как только продажи пошли стабильно, **оформлять ИП**. Это 3 дня через Госуслуги, работать в найме при этом можно.
- **Не принимать много переводов на личную карту от незнакомых людей.** С 2025–2026 банки по закону 115-ФЗ и правилам против «дропов» блокируют карты с частыми входящими переводами от чужих людей. Безопаснее принимать деньги через Авито или наличными / переводом при встрече.

## Рекомендуемая схема пилота

```
                   ┌─ Новосибирск ──────────────────────────────────────────┐
Покупатель на сайте│  1. Заказ с сайта → Ире в MAX                           │
  или на Авито  ───┤  2. Ира звонит/пишет, договаривается                    │
                   │  3a. Самовывоз / встреча → оплата при получении          │
                   │  3b. Курьер Яндекс Доставки → покупатель платит доставку │
                   └─────────────────────────────────────────────────────────┘
                   ┌─ Другой город ─────────────────────────────────────────┐
                   │  Через Авито Доставку: покупатель платит на Авито,      │
                   │  Ира сдаёт посылку в ПВЗ, деньги приходят после         │
                   │  получения, за вычетом комиссии Авито                    │
                   └─────────────────────────────────────────────────────────┘
```

### 1. Новосибирск — основной канал

| Способ | Как | Цена для покупателя | Оплата |
|--------|-----|---------------------|--------|
| **Самовывоз / встреча** | Ира назначает место (метро, ТЦ, у дома) | 0 ₽ | наличные или перевод при получении |
| **Яндекс Доставка: пункт → пункт** ✅ основной | Ира сдаёт пакет в ближайший ПВЗ Яндекса, покупатель забирает в своём ПВЗ, обычно на следующий день | ≈ 100–180 ₽ | Ира оплачивает отправку в приложении → покупатель должен заплатить ей заранее (перевод) |
| **Авито Доставка по городу** ✅ основной | так же через пункт; покупатель оформляет на Авито | ≈ 100–300 ₽ (считает Авито) | покупатель платит Авито — безопасно, без переводов на карту |
| Курьер «Экспресс» (Яндекс Go) | срочно, за 1–2 часа | ≈ 155–400 ₽ | только если покупатель сам просит срочно |

На первые заказы этого хватит. Сайт присылает заявку в MAX, дальше Ира договаривается с покупателем голосом.

### 2. Другие города — Авито Доставка

Как работает:
1. На каждый товар есть объявление на Авито (в студии кнопка «Текст для Авито»).
2. Покупатель жмёт «Купить с доставкой» и **платит Авито** (безопасная сделка).
3. Ира получает код отправления и относит пакет в пункт приёма (Почта, Boxberry, СДЭК, ПВЗ Авито / Яндекса — какой ближе).
4. Покупатель забирает посылку → через сутки деньги на кошельке Авито → вывод на карту.

Деньги и комиссия:
- Комиссия с продавца — **≈ 2–13,5 %** (с апреля 2026 считается индивидуально, минимум ≈ 100–150 ₽ за заказ, удерживается при выводе).
- ⚠️ **Для носков за 200–370 ₽ минимальная комиссия 100–150 ₽ съедает половину цены.** Поэтому на Авито лучше выставлять **наборы**: «3 пары — 690 ₽», «5 пар — 1 090 ₽», боксеры коробкой 2 400 ₽.
- Доставку оплачивает покупатель. Работает для частных лиц, ИП не нужен.
- Плюс: деньги принимает Авито, а не личная карта Иры, поэтому риска блокировки нет.

Покупателю с сайта из другого города Ира отвечает: «оформим через Авито Доставку» и присылает ссылку на объявление. На сайте такой вариант уже есть в форме заказа.

### 3. Когда будет ИП (этап 2)

- Онлайн-оплата прямо на сайте: ЮKassa / Робокасса, оплата картой и СБП, чек формируется сам (облачная касса).
- СДЭК / Яндекс Доставка по договору: автоматический расчёт стоимости в корзине.
- Авито Доставка тоже остаётся.

## Расчёт логистики (Новосибирск, пункт → пункт)

**Исходные (проверить!):** пара носков в пакете ≈ 60–80 г, 3 пары ≈ 250 г, 5 пар ≈ 400 г — всё это самый маленький размер посылки (S). Яндекс ПВЗ→ПВЗ по городу ≈ **150 ₽** (диапазон 100–180), Авито по городу ≈ **150–250 ₽** + комиссия Авито с Иры **мин. ≈ 100–150 ₽** за заказ.

> 🔎 Точную цену Ира узнает за минуту: приложение Яндекс Go → Доставка → «Посылка» (или dostavka.yandex.ru) → откуда/куда — два ПВЗ Новосибирска, размер S. Впишем сюда реальную цифру.

### Правило: «от 3 пар — доставка бесплатно, меньше — плюс доставка»

Носки 200–250 ₽ (середина ≈ 230 ₽), доставка ≈ 150 ₽:

| Заказ | Покупатель платит | Ира получает (Яндекс, сама платит доставку) | Доставка — доля выручки |
|-------|-------------------|---------------------------------------------|--------------------------|
| 1 пара | 230 + **150** = 380 ₽ | 230 ₽ | 0 % (платит покупатель) |
| 2 пары | 460 + **150** = 610 ₽ | 460 ₽ | 0 % |
| **3 пары** | **690 ₽**, доставка 0 | 690 − 150 = **540 ₽** | **22 %** |
| 5 пар | 1 150 ₽, доставка 0 | 1 000 ₽ | 13 % |
| Коробка боксеров | 2 400 ₽, доставка 0 | 2 250 ₽ | 6 % |

**Вывод:** бесплатная доставка от 3 пар стоит Ире ≈ **50 ₽ с каждой пары** в заказе из трёх. Если закупка пары ≈ 80–120 ₽, это нормально. Если дороже, порог лучше ставить **от 4 пар** или делать не «бесплатно», а «доставка 99 ₽».

### Через Авито по городу

| Заказ | Покупатель платит | Ира получает (−комиссия ≈ 100–150 ₽, мин.) |
|-------|-------------------|---------------------------------------------|
| 1 пара 230 ₽ | 230 + доставка Авито | ≈ 80–130 ₽ ❌ невыгодно |
| Набор 3 пары 690 ₽ | 690 + доставка | ≈ 540–590 ₽ ✅ |
| Коробка боксеров 2 400 ₽ | 2 400 + доставка | ≈ 2 150–2 300 ₽ ✅ |

👉 На Авито — **только наборы от 3 пар** и боксеры. Поштучно — на сайте, самовывоз или Яндекс.

- [ ] Реальная цена Яндекс ПВЗ→ПВЗ по Новосибирску (размер S).

## Что поменять на сайте под пилот (делаю я, ≈ 30 минут)

Сейчас в форме заказа такие способы: «Самовывоз», «СДЭК», «Почта России», «Авито Доставка». Под пилот лучше так:

| Было | Станет |
|------|--------|
| Самовывоз | **Встреча / самовывоз в Новосибирске** — бесплатно |
| СДЭК | **Яндекс Доставка в пункт выдачи по Новосибирску** — «≈ 150 ₽, от 3 пар бесплатно» |
| Почта России | убрать на пилот |
| Авито Доставка | **Авито Доставка** (по городу и в другие города) |

Плюс:
- «Бесплатная доставка от 2 000 ₽» → **«от 3 пар — доставка бесплатно»** (считать по количеству, а не по сумме); в корзине подсказка «добавьте ещё 1 пару — и доставка бесплатно».
- Поле «Telegram покупателя» → «Как связаться: звонок / MAX / SMS».
- Страницу `/delivery` переписать под эту схему.
- Наборы для Авито («3 пары за …») — добавить в каталог, если Ира согласна.
