# Запуск «Носи носки» по-настоящему — что делать дальше

Сейчас есть **демо** на GitHub Pages. Его можно показывать, но заказы там не уходят, остатки не списываются, а фотостудия работает только на твоём компьютере. Чтобы магазин заработал для Иры, нужно пройти шаги ниже.

## Порядок шагов

| # | Шаг | Кто | Сколько стоит | Инструкция |
|---|-----|-----|---------------|------------|
| 0 | Решения Иры: ИП или самозанятость, ФИО/ИНН, куда слать заказы | Ира | 0 ₽ | [5_юридическое.md](5_юридическое.md) |
| 1 | Купить домен (адрес сайта) | ты | 200–900 ₽/год | [1_домен.md](1_домен.md) |
| 2 | Арендовать сервер (VPS) в России | ты | 300–600 ₽/мес | [2_сервер.md](2_сервер.md) |
| 3 | Выложить сайт на сервер и подключить домен | Claude + ты | 0 ₽ | [3_сайт_на_сервер.md](3_сайт_на_сервер.md) |
| 4 | Уведомления о заказах: Telegram-бот + почта (+ в приложении) | ты + Ира | 0 ₽ | [6_уведомления_о_заказах.md](6_уведомления_о_заказах.md) |
| 5 | Фотостудия для Иры: отдельное приложение с паролем | Claude + ты | 0 ₽ + генерации | [4_студия_для_иры.md](4_студия_для_иры.md) |
| 6 | Склад: Google Таблица (телефон + компьютер) | ты + Ира | 0 ₽ | [8_склад_остатки.md](8_склад_остатки.md) |

Шаги 1 и 2 займут около часа, нужны только паспорт и карта. Шаги 3 и 5 делаю я (Claude) по команде «выкладываем на сервер». От тебя нужен доступ к серверу (IP и пароль) и к панели домена.

## Итог по деньгам

| Что | Цена |
|-----|------|
| Сервер VPS (сайт + студия на одном) | ≈ 300–600 ₽/мес |
| Домен `.ru` | ≈ 200–900 ₽/год |
| Фото в студии (Nano Banana) | ≈ 6–7 ₽ за фото, ≈ 20–25 ₽ за модель |
| Бот, таблица склада, SSL-сертификат | 0 ₽ |
| **Итого** | **≈ 350–700 ₽/мес** |

## Как это будет выглядеть в конце

```
https://nosinoski.ru            ← магазин для покупателей
https://studio.nosinoski.ru     ← фотостудия Иры (вход по паролю)
Telegram + почта + приложение   ← сюда приходят заказы
Google Таблица                  ← остатки, Ира правит с телефона
```

Ира открывает студию с телефона или ноутбука, загружает фото носков, получает красивые фото и текст для Авито, нажимает «Опубликовать», и через минуту-две товар на сайте.

## Чек-лист

- [ ] Ира: ИП или самозанятая (самозанятой нельзя перепродавать чужой товар!)
- [ ] Ира: ФИО/ИНН для политики конфиденциальности
- [ ] Ира: Telegram или MAX для заказов
- [ ] Куплен домен
- [ ] Арендован VPS, есть IP и пароль root
- [ ] Сайт выложен, домен открывается по https
- [ ] Бот присылает тестовый заказ
- [ ] Студия открывается по паролю, фото публикуется на сайт
- [ ] Склад подключён
- [ ] Уведомление в Роскомнадзор об обработке персональных данных
