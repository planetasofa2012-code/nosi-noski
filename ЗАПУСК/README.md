### Как устроено сейчас (реально, с 15.10.2026)

- Сайт — **Timeweb Cloud App Platform → Frontend**, приложение `nosinoski` (id **270753**), тариф «1 ₽» (пресет 2801, Москва). VPS не нужен.
- Источник — ветка **`site`** репозитория `planetasofa2012-code/nosi-noski`: там лежат уже собранные статичные файлы (index.html в корне). Framework `static-nobuild`, без команды сборки, папка `/`. Автодеплой включён: новый коммит в `site` → сайт обновляется за минуту.
- Домены `nosinoski.ru` и `www.nosinoski.ru` привязаны к приложению, A-записи → `178.209.127.53`. SSL — бесплатный Let's Encrypt (выпускается автоматически после того, как домен начнёт резолвиться).
- Технический адрес: https://planetasofa2012-code-nosi-noski-8c53.twc1.net

**Обновить сайт** (после правок товаров/фото) — из корня проекта:

```bash
bash deploy/publish-site.sh
```

Скрипт соберёт сайт и запушит его в ветку `site`, дальше Timeweb всё сделает сам.

Ира открывает студию с телефона или ноутбука, загружает фото носков, получает красивые фото и текст для Авито, нажимает «Опубликовать», и через минуту-две товар на сайте.
