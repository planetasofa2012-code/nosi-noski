# 4. Фотостудия для Иры — отдельное приложение

## Сейчас

Студия (`studio/`) — программа, которая работает **только на твоём компьютере** (`studio/start.bat` → http://127.0.0.1:4545). Она:
- берёт фото носков и делает предметные и лайфстайл-фото через Nano Banana (OpenRouter);
- пишет текст объявления для Авито;
- показывает склад;
- сохраняет фото прямо в каталог сайта (`shop/public/products/…` + `products.json`).

Ира пользоваться ей не может: нужен твой компьютер, а сайт после сохранения надо пересобирать вручную.

## Цель

```
Ира (телефон/ноутбук) ──▶ https://studio.nosinoski.ru  (вход по паролю)
      1. «Новый товар»: название, категория, цена, цвета, размеры, состав
      2. Загрузить свои фото → выбрать сцену → получить AI-фото
      3. Отметить лучшие → «Опубликовать»
      4. Через 1–2 минуты товар на сайте; текст для Авито — кнопкой «Скопировать»
```

Студия живёт на **том же сервере**, что и сайт: так она пишет в каталог напрямую, и ничего синхронизировать не нужно.

## Что нужно доделать в коде (делаю я, ≈ 1 сессия)

| # | Доработка | Зачем |
|---|-----------|-------|
| 1 | **Вход по паролю** (пароль в `.env` на сервере, сессия в cookie, блокировка после 5 ошибок) | сейчас студия открыта всем, кто знает адрес, и тратит деньги на генерации |
| 2 | Слушать не только `127.0.0.1`: на сервере закрыта за nginx + https | доступ из интернета, ключ OpenRouter остаётся на сервере |
| 3 | **Форма «Новый товар» и редактирование** (цена, цвета, размеры, состав, «скрыть с сайта») | сейчас новые товары добавляю я в `products.json` |
| 4 | **Кнопка «Опубликовать»** → пересборка сайта и перезапуск без простоя | иначе изменения не видны на сайте |
| 5 | Загрузка фото с телефона: HEIC → JPEG, сжатие до 1200px, поворот по EXIF | Ира снимает на iPhone (как в этой партии) |
| 6 | **Лимит расходов** на генерации: например, $5 в месяц, счётчик в шапке | чтобы случайно не потратить много |
| 7 | Подсказка «положите носок резинкой вверх» + проверка надписей | ошибки, которые уже ловили (перевёрнутый смайл, «Sporto») |
| 8 | Ярлык на телефон (PWA): «Добавить на экран Домой», выглядит как приложение | открывается одним касанием, без адресной строки |
| 9 | Каждое «Опубликовать» → коммит в git (история и откат) | если Ира что-то сломает, откатываемся |

## Варианты, если нужно совсем «приложение»

| Вариант | Как | Стоимость | Советую? |
|---------|-----|-----------|----------|
| **A. Веб-приложение (PWA) на сервере** | то, что описано выше; на телефоне — иконка на экране | 0 ₽ сверх сервера | ✅ да, начинаем с этого |
| B. Telegram-бот-студия | Ира шлёт фото боту → получает AI-фото → «Опубликовать» | 0 ₽ | позже, как дополнение: удобно, но меньше возможностей |
| C. Программа на ноутбук Иры (как сейчас у тебя) | установщик Node + ярлык | 0 ₽ | ❌ нужен её ноутбук всегда включённым, сайт всё равно на сервере |
| D. Приложение в App Store / Google Play | отдельная разработка | $99/год Apple + недели работы | ❌ избыточно |

## Деньги на генерации

- 1 фото ≈ **$0.07 (6–7 ₽)**, модель носков ≈ **20–25 ₽**.
- Баланс OpenRouter пополняешь ты (иностранная карта или крипта). Ира видит в студии только счётчик и лимит.
- Другой вариант — ключ Google Gemini напрямую (студия его тоже поддерживает: `GEMINI_API_KEY`). Из РФ без прокси он не работает.
