# 3. Сайт на сервер + домен + бот

Это делаю я (Claude) по SSH, когда есть сервер и домен. Здесь записано, что именно будет сделано, чтобы можно было проверить или повторить.

## Схема

```
Покупатель ──https──▶ nginx (порт 443, бесплатный SSL Let's Encrypt)
                         ├─ nosinoski.ru         → магазин  (Next.js, порт 3333)
                         └─ studio.nosinoski.ru  → студия   (Node, порт 4545, пароль)
Магазин ── заказ ──▶ Telegram / MAX
Магазин ── остатки ─▶ Google Таблица (Apps Script)
```

## Шаги на сервере

1. **Защита сервера:** обновления, пользователь `shop` вместо root, вход по SSH-ключу, firewall (открыты только 22, 80, 443), fail2ban.
2. **Софт:** Node.js 24, git, nginx, certbot, pm2 (держит сайт и студию запущенными и поднимает после перезагрузки).
3. **Код:** `git clone https://github.com/planetasofa2012-code/nosi-noski` в `/home/shop/nosi-noski`.
4. **Настройки** — файл `shop/.env.local` на сервере (в git НЕ попадает):
   ```
   NEXT_PUBLIC_SITE_URL=https://nosinoski.ru
   TELEGRAM_BOT_TOKEN=...   TELEGRAM_CHAT_ID=...
   MAX_BOT_TOKEN=...        MAX_CHAT_ID=...
   STOCK_API_URL=...        STOCK_API_KEY=...
   ```
5. **Сборка и запуск:** `cd shop && npm ci && npm run build`, затем `pm2 start "npm start -- -p 3333" --name shop`.
6. **nginx + SSL:** конфиг на два адреса, `certbot --nginx -d nosinoski.ru -d www.nosinoski.ru -d studio.nosinoski.ru`. Сертификат продлевается сам.
7. **DNS** у регистратора: A-записи на IP сервера (см. [1_домен.md](1_домен.md)).
8. **Проверка:** главная, каталог, карточка, тестовый заказ → пришёл в бот, остаток списался, `https://nosinoski.ru/avito.xml` открывается.
9. **Бэкап:** раз в сутки архив `products.json` + фото товаров (cron), плюс всё лежит в git.

## Как обновлять сайт потом

- Товары и фото меняет Ира через студию (кнопка «Опубликовать», см. [4_студия_для_иры.md](4_студия_для_иры.md)).
- Правки кода: я делаю их у тебя на компьютере → `git push` → на сервере `bash deploy/update.sh` (скрипт сделаю при выкладке: `git pull`, сборка, перезапуск без простоя).

## Бот для заказов

Ира выбирает, куда приходят заказы: **Telegram**, **MAX** или оба сразу.

**Telegram (5 минут):**
1. В Telegram открыть **@BotFather** → `/newbot` → имя «Носи носки заказы» → username, например `nosinoski_orders_bot`.
2. BotFather пришлёт **токен** вида `123456:ABC...` — это `TELEGRAM_BOT_TOKEN`.
3. Ира пишет своему боту `/start`.
4. Я узнаю её `chat_id` и пропишу оба значения на сервере. Если заказы должны видеть двое (Ира + помощник), делаем группу и добавляем туда бота.

**MAX:**
1. Создать бота у **@MasterBot** в MAX, получить токен.
2. На компьютере: `cd shop && npm run max:setup`. Помощник сам найдёт ID чата и пришлёт тестовое сообщение.
