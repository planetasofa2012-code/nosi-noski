### Результат
MVP работает локально. Для запуска нужны данные друзей, токен бота и вход в Vercel.

### Решения
- Каталог — JSON, заказы — в Telegram, без БД на MVP (ПДн не храним на сайте).
- Остатки — Google Таблица через Apps Script (правка с телефона, автосписание), fallback — JSON.
- Фото — Nano Banana 2 (`google/gemini-3.1-flash-image`) через OpenRouter, ключ уже есть в `~/.env.keys`.
- Фотостудия — локальный сервис, ключ не уходит в интернет.
- Авито: кнопка + помощник объявлений + XML-фид (автозагрузка платная — включат сами).

## Полезные находки

| Находка | Контекст |
|---------|----------|
| OpenRouter `/api/v1/models` — Nano Banana 2, 2 Lite, 2.1, Pro | проверено 2026-10-14 |
| В объявлениях Авито нельзя внешние ссылки | только «смотрите профиль» |
| Автозагрузка Авито для товаров = тариф + «Расширенная» подписка | фид готовим заранее |
| MAX Bot API: домен `platform-api2.max.ru`, `Authorization: <token>` без Bearer | токен в query больше не принимается; лимит 2 сообщения/сек в один чат; для событий из групп бот должен быть админом |
| Next 16.4: `cacheComponents: true` по умолчанию | `export const revalidate` запрещён → `'use cache'` + `cacheLife` + `cacheTag`; `searchParams` — только внутри `<Suspense>` |
| Apps Script POST отвечает 302 | `fetch` с redirect follow сам забирает ответ GET-ом, тело `text/plain` |
| rtk ломает `next start` в фоне | запускать через `rtk proxy npx next start` |
| Chrome headless: мин. ширина окна ~500px | мобильные скриншоты снимать при 500px |
| OpenRouter Nano Banana 2: ~13 сек, $0.067 за 1 фото 4:5 | ответ в `choices[0].message.images[].image_url.url`, `image_config.aspect_ratio` работает |
| Nano Banana дорисовывает брендовую обувь | в промпте явно: plain unbranded shoes, no logos |
| Бельё и носки надлежащего качества не подлежат возврату | Постановление № 2463, но действует право отказа при дистанционной продаже |
