# Стадия 0 — Исследование

> Проект: **Мини-интернет-магазин носков и нижнего белья** (для Иры и друзей)
> Дата: 2026-10-14

---

## 1. Схема проекта (исходная концепция)

```
Покупатель ──► Сайт-витрина (каталог → карточка → корзина → заказ)
                     │
                     ▼
             Telegram-бот продавца  ◄── уведомление о заказе (имя, телефон, состав, доставка)
                     │
                     ▼
             Продавец связывается, принимает оплату (СБП / при получении), отправляет

Продавец ──► Фотостудия (отдельный сервис)
               фото носков с телефона ──► Nano Banana ──► предметка / на модели / лайфстайл
                     │
                     ▼
             готовые фото ──► в карточки товара на сайте
```

Исходная проблема: друзья торгуют носками и бельём, но **«не очень успешно»**. Типичные причины в нише (см. п. 5):
- нет нормальной витрины — товар показывают в переписке фотками «с кровати»;
- плохие фото товара (главный фактор покупки в одежде онлайн);
- нет понятного каталога с размерами/ценами — каждый вопрос «а сколько стоит?» отнимает время и теряет клиента;
- продажи только через знакомых, нет повторных продаж.

## 2. Технологический стек (октябрь 2026)

| Слой | Выбор | Почему |
|------|-------|--------|
| Витрина | **Next.js 16 (App Router) + TypeScript + Tailwind 4** | быстрая статическая сборка, SEO, бесплатный хостинг |
| Хостинг | **Vercel** (бесплатный план Hobby) | деплой за минуту, HTTPS, свой домен |
| Каталог | **JSON-файл** в репозитории (MVP) → Supabase (v2, админка) | для 20–100 товаров база не нужна |
| Корзина | `localStorage` в браузере | без регистрации и аккаунтов |
| Заказы | **Telegram Bot API** → чат продавца | продавцы уже живут в Telegram, бесплатно |
| Оплата | MVP: СБП-перевод / при получении; v2: **ЮKassa** или **Робокасса** (для самозанятых, чеки автоматом) | не нужен эквайринг на старте |
| Фото | **Nano Banana** через **OpenRouter** (ключ уже есть) | реалистичные фото товара и «на модели» из одного фото с телефона |

### 2.1. Модели Nano Banana на OpenRouter (проверено через API 2026-10-14)

| ID | Название | Вход / выход за 1M токенов | Для чего |
|----|----------|------|----------|
| `google/gemini-3.1-flash-image` | Nano Banana 2 | $0.5 / $3 | **по умолчанию**: быстро, дёшево, хорошо держит товар |
| `google/gemini-3.1-flash-lite-image` | Nano Banana 2 Lite | $0.25 / $1.5 | черновики, массовая генерация |
| `google/gemini-3-pro-image` | Nano Banana Pro | $2 / $12 | обложки, главные фото, до 14 референсов |
| `google/gemini-nano-banana-2.1` | Nano Banana 2.1 | $1.5 / $7.5 | новая версия, протестировать |

Ориентир по стоимости: обычно **~$0.04–0.07 за картинку** для Flash-версий и **~$0.13–0.24** для Pro. Каталог на 30 товаров × 4 фото ≈ 120 картинок ≈ **$5–8** (~500–800 ₽). Точную цену проверим на первом тесте.

## 3. Конкуренты и референсы

### 3.1. St. Friday Socks (СПб)
Носочная фабрика из Петербурга, яркий дизайн, коллаборации (Русский музей, фонд «Антон тут рядом», Stereoleto), продажи через свой сайт, Спортмастер и партнёрские магазины.
**Что взять:** у каждой пары есть история/название, тематические коллекции («ко дню города»), подарочные наборы, носки как подарок.

### 3.2. Маркетплейсы (Wildberries, Ozon)
Огромный трафик, но комиссия 15–30 %, логистика, штрафы, демпинг, нужен ИП/самозанятость, сложные карточки.
**Вывод:** маркетплейс — отдельный канал на будущее. Свой сайт нужен как **визитка и витрина** для своей аудитории, соцсетей, Авито и сарафана.

### 3.3. Telegram Mini Apps-магазины
Кейсы 2026: убирание лишних шагов даёт +20–40 % к конверсии; клиент покупает «не выходя из чата».
**Вывод:** сайт делаем адаптивным под телефон так, чтобы потом в v2 его можно было открыть как Mini App внутри Telegram-бота без переделки.

### 3.4. Авито, совместные покупки, локальные TG-группы
Реальные каналы для малых продавцов носков (по обсуждению в Т—Ж: «гараж носков» продают через Авито с доставкой, группы «продам в …», организаторов СП).
**Вывод:** ссылка на сайт в каждом объявлении Авито и посте → клиент видит весь ассортимент, а не одну пару.

### 3.5. AI-фото для карточек (Nano Banana)
Селлеры WB/Ozon массово делают из одного фото с телефона: предметку на белом, разные ракурсы, фото на модели, сезонный фон. Nano Banana хорошо сохраняет форму, принт и мелкие детали товара. Pro принимает до 14 референсов (товар, модель, стиль).
**Вывод:** это главный «рычаг» проекта — без фотографа и студии получить витрину уровня бренда.

## 5. Почему продажи «не очень» и что даст сайт

| Проблема | Решение в проекте |
|----------|-------------------|
| Плохие фото | Фотостудия на Nano Banana: предметка + на модели + лайфстайл |
| Нет каталога / цен | Карточки с ценой, размерами, составом, наличием |
| Клиент «подумаю» и пропал | Корзина + заказ в 3 поля, без регистрации |
| Мелкий чек | Наборы (3/5/7 пар), «подарочная упаковка», «с этим берут» |
| Нет повторных продаж | Контакт клиента приходит в Telegram → база для рассылки (v2) |
| Покупают только знакомые | Одна ссылка для Авито / Instagram / ВК / TG-канала |

## 6. Юридические моменты (важно знать)

- **Форма:** продавать стабильно — лучше оформить **самозанятость** (налог 4–6 %, чек через «Мой налог») или ИП. Самозанятые могут перепродавать **только товары собственного производства**; для перепродажи покупных носков/белья нужен **ИП**. ⚠️ Уточнить у друзей.
- **Возврат:** бельевые и чулочно-носочные изделия надлежащего качества **не подлежат возврату/обмену** (Перечень, Постановление Правительства № 2463). Но при **дистанционной продаже** покупатель имеет право отказаться от товара в течение 7 дней, если он не был в употреблении и сохранён товарный вид — указать честно в условиях.
- **Персональные данные (152-ФЗ):** форма заказа собирает имя и телефон → нужна галочка согласия и страница «Политика конфиденциальности». Формально оператор ПДн должен уведомить Роскомнадзор и хранить данные россиян на серверах в РФ. На MVP заказы не храним на сайте — они сразу уходят в Telegram продавцу; в v2 с базой данных — выбрать хостинг БД в РФ.
- **AI-фото:** товар на картинке должен совпадать с реальным (цвет, принт, состав), иначе будут возвраты и жалобы. Фото моделей — сгенерированные люди, не реальные лица.

## 7. Тренды 2026

- 🔥 AI-фото товара стало стандартом у малых селлеров — без него витрина выглядит «бедно».
- 🔥 Покупки в мессенджерах (Telegram Mini Apps, заказ в чате) растут быстрее сайтов.
- 🔥 Носки как подарок и «настроение»: яркие принты, наборы, тематические коллекции.
- 📊 80 %+ трафика в одежде — с телефона → мобильная вёрстка в приоритете.

## 8. SWOT

| | |
|---|---|
| **S — сильные** | почти бесплатно; быстрый запуск; AI-фото уровня студии; заказ в Telegram без лишних систем |
| **W — слабые** | нет онлайн-оплаты в MVP; каталог правится через файл (нужен я или простая инструкция) |
| **O — возможности** | Telegram Mini App; наборы и подписка «носки каждый месяц»; выход на Авито/WB с теми же AI-фото |
| **T — угрозы** | конкуренция с маркетплейсами по цене; несоответствие AI-фото реальному товару; требования 152-ФЗ |

## 9. Выводы и рекомендации

1. Делаем **лёгкую мобильную витрину** на Next.js + Vercel, каталог в JSON, заказ уходит в Telegram — это 90 % пользы за 10 % сложности.
2. Делаем **отдельную фотостудию** (локальный сервис) на Nano Banana 2 через OpenRouter: загрузил фото с телефона → выбрал сцену → получил фото → нажал «в каталог».
3. Онлайн-оплату, админку и Mini App — во v2, когда пойдут заказы.
4. Добавить продающие механики сразу: наборы, «подарок», «с этим берут», бейджи «хит/новинка».

## 10. Связка с Авито (дополнение по запросу)

Авито для малых продавцов носков — один из главных каналов (трафик + «Авито Доставка», которой покупатели доверяют). Варианты интеграции, от простого к сложному:

| Уровень | Как работает | Что нужно | Цена |
|---------|--------------|-----------|------|
| **A. Авито-помощник** (MVP) | в фотостудии кнопка «Объявление для Авито»: готовый заголовок (≤ 50 символов), описание, цена, фото в нужном формате → скопировать и вставить на Авито | ничего | 0 ₽ |
| **B. Кнопка на сайте** (MVP) | в карточке товара «Купить на Авито с доставкой» → ссылка на объявление (поле `avitoUrl`) | ссылка на объявление | 0 ₽ |
| **C. Автозагрузка (XML-фид)** (MVP-подготовка, включить позже) | сайт сам отдаёт `/avito.xml` из того же каталога → Авито раз в сутки создаёт/обновляет объявления, цены и остатки | на Авито: тариф + подписка «Расширенная/Максимальная» для категорий кроме недвижимости и транспорта | платно, по тарифам Авито |
| **D. Avito API** (v2) | сообщения покупателей с Авито → в тот же Telegram-бот; статистика объявлений | `client_id` / `client_secret` бизнес-аккаунта, часть методов — только с подпиской | платно |

⚠️ **Правила Авито:** в тексте объявления **нельзя** ставить ссылки на сторонние сайты и контакты вне Авито — объявление заблокируют. Поэтому в описании пишем «Ещё N моделей — в моём профиле», а ссылку на сайт — только в профиле (для магазина) и в соцсетях. Названия категорий и полей для фида нужно сверить с актуальным шаблоном из кабинета «Автозагрузка → Правила и шаблоны».

**Вывод:** в MVP делаем A + B + готовый фид C (включат, когда купят тариф). D — во v2, если пойдёт объём.
