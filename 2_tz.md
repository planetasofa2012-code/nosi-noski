# Стадия 2 — Техническое задание

## 1. Общее описание

Два независимых приложения в одной папке:
- `shop/` — интернет-магазин (Next.js, деплой на Vercel);
- `studio/` — фотостудия (локальный Node.js-сервис, запускается на компьютере продавца, ключ API не уходит в интернет).

Связь между ними — через файлы: студия сохраняет картинки в `shop/public/products/<slug>/` и дописывает пути в `shop/src/data/products.json`.

### 2.3. Товарные остатки (по позициям)
Позиция (SKU) = товар × размер × цвет, например `socks-avocado-36-39-green`.

| # | Фича | Критерий готовности |
|---|------|---------------------|
| W1 | Модель вариантов | у товара массив `variants[]` со `sku`, `size`, `color`, `stock` |
| W2 | Источник остатков | **Google Таблица «Склад»** (лист `stock`: `sku`, `товар`, `размер`, `цвет`, `остаток`) через Apps Script веб-приложение; без настройки — `stock` из `products.json` |
| W3 | Обновление на сайте | остатки кэшируются на 2 мин (ISR / revalidate), правка в таблице появляется на сайте сама |
| W4 | Витрина | размер/цвет без остатка — зачёркнут и недоступен; «Осталось 2 шт» при остатке ≤ 3; товар без остатков — «Нет в наличии», в конце каталога |
| W5 | Корзина | нельзя положить больше, чем есть; при оформлении сервер перепроверяет остатки, при нехватке — понятная ошибка с актуальным количеством |
| W6 | Списание | после успешного заказа `POST` в Apps Script → остаток уменьшается, строка заказа пишется на лист `log` |
| W7 | Мало осталось | если после списания остаток ≤ 1 — в Telegram продавцу «⚠️ Заканчивается: …» |
| W8 | Шаблон таблицы | скрипт `npm run stock:export` выгружает все SKU из каталога в CSV для импорта в таблицу; файл `stock/apps-script.gs` + инструкция |
| W9 | Склад в студии | вкладка «Склад» в фотостудии: таблица всех позиций с остатками (чтение из того же источника) |

## 5. API-контракты

### 5.1. `POST /api/order` (магазин)
Запрос:
```json
{
  "customer": { "name": "Анна", "phone": "+79991234567", "telegram": "@anna", "consent": true },
  "delivery": { "method": "cdek", "address": "Москва, ПВЗ на Ленина 1" },
  "comment": "",
  "items": [{ "sku": "socks-avocado-36-39-green", "qty": 2 }]
}
```
Сервер **пересчитывает цены по своему каталогу** (не доверяет клиенту), формирует номер `M-YYMMDD-XXXX`.
Ответ `200`: `{ "ok": true, "orderId": "M-261014-4821" }`; `400`: `{ "ok": false, "error": "…" }`.

### 5.2. Склад (Google Apps Script веб-приложение)
- `GET  <STOCK_API_URL>?key=<STOCK_API_KEY>` → `{ "stock": { "<sku>": 5, … } }`
- `POST <STOCK_API_URL>` `{ "key": "…", "orderId": "M-…", "items": [{ "sku": "…", "qty": 2 }] }` → `{ "ok": true, "stock": { "<sku>": 3 } }`
Скрипт списывает остатки под `LockService` (два заказа одновременно не уйдут в минус).

### 5.3. Telegram Bot API
`POST https://api.telegram.org/bot<TOKEN>/sendMessage` — `chat_id`, `text` (HTML), `parse_mode: "HTML"`.
Если переменные не заданы — заказ пишется в лог сервера (режим разработки), пользователь всё равно видит «спасибо».

### 5.4. Фотостудия: `POST /api/generate`
Запрос: `{ "images": ["data:image/jpeg;base64,…"], "scene": "model-legs", "prompt": "доп. пожелания", "model": "google/gemini-3.1-flash-image", "count": 2 }`
→ OpenRouter `POST /api/v1/chat/completions` с `modalities: ["image","text"]`, картинки — в `content` как `image_url`.
Ответ: `{ "images": ["data:image/png;base64,…"] }`.

### 5.5. Фотостудия: `POST /api/save`
`{ "slug": "socks-avocado", "image": "data:…", "asCover": false }` → файл в `shop/public/products/<slug>/<n>.png`, путь в `products.json`.

## 6. Нефункциональные требования

### 6.1. Производительность
- Страницы каталога — статические (SSG), LCP < 2,5 с на 4G.
- Картинки через `next/image` (WebP/AVIF, ленивые).

### 6.2. Безопасность
- Ключи только в переменных окружения: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `STOCK_API_URL`, `STOCK_API_KEY` (магазин), `OPENROUTER_API_KEY` или `GEMINI_API_KEY` (студия).
- Студия слушает только `127.0.0.1`, в интернет не публикуется.
- Валидация заказа на сервере, ограничение длины полей, honeypot-поле против ботов.
- В `/api/save` slug проверяется по каталогу (защита от записи в произвольный путь).

### 6.3. Право
- Галочка согласия на обработку ПДн + страница политики.
- Условия возврата по закону (бельё/носки надлежащего качества — не подлежат возврату, кроме права отказа при дистанционной продаже до получения/в течение 7 дней при сохранении вида).
