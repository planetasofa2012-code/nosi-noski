# «Носи носки» — мини-магазин носков

**Демо:** https://planetasofa2012-code.github.io/nosi-noski/ · **Демо студии:** https://planetasofa2012-code.github.io/nosi-noski/studio/
Обновить демо: `bash deploy/publish-demo.sh`

Две части:
- **`shop/`** — сайт-магазин (каталог, карточки, корзина, заказ в Telegram, остатки, фид для Авито).
- **`studio/`** — фотостудия на Nano Banana: фото с телефона → предметка / на модели / лайфстайл → сразу в товар. Плюс помощник объявлений для Авито и просмотр склада.

Документы проекта: `0_research.md` → `1_idea.md` → `2_tz.md` → `3_architecture.md` → `4_design.md` → `5.1_tasks.md`, журнал — `PROTOCOL.md`.

## Быстрый старт (на компьютере)

Нужен Node.js 22+.

```bash
cd shop
npm install
npm run dev          # магазин → http://localhost:3333
npm run studio       # фотостудия → http://127.0.0.1:4545  (или двойной клик studio/start.bat)
```

## Как менять товары

Все товары — в файле **`shop/src/data/products.json`**. У каждого товара:

| Поле | Что это |
|------|---------|
| `slug` | адрес страницы латиницей, например `socks-avocado` (не менять после запуска) |
| `title`, `price`, `oldPrice` | название, цена, старая цена (для скидки, можно не указывать) |
| `category` | `socks`, `women`, `men` или `sets` |
| `colors` | цвета: `id` (латиницей), `name`, `hex` |
| `variants` | **позиции**: `sku` (= slug-размер-цвет), `size`, `color` (id цвета), `stock` (остаток) |
| `images` | фото — их добавляет фотостудия, первое — главное |
| `badges` | `hit` (хит), `new` (новинка) |
| `popularity` | чем больше, тем выше в списке |
| `avitoUrl` | ссылка на объявление на Авито — появится кнопка «Купить на Авито» |

Название магазина, телефон, Telegram, порог бесплатной доставки — в **`shop/src/lib/site.ts`**.

## Фото через Nano Banana

1. `npm run studio` → откроется студия.
2. Загрузите 1–3 фото товара с телефона (однотонный фон, дневной свет).
3. Выберите сцену (предметка, flat-lay, на ногах, модель в белье, улица, подарок) и модель.
4. «Сгенерировать» → понравившееся фото «＋ В товар» или «★ Главным».

Ключ берётся из `~/.env.keys` (`OPENROUTER_API_KEY`) или из `GEMINI_API_KEY`. Цена ≈ **$0.07 за фото** на Nano Banana 2 (проверено). Все генерации сохраняются в `studio/output/`.

⚠️ Фото должно честно показывать товар (цвет, принт). Если модель что-то «додумала» — перегенерируйте.

## Остатки

По умолчанию — поле `stock` в `products.json`. Для удобной работы с телефона подключите Google Таблицу: инструкция в **`stock/README.md`** (5 минут). После этого остатки списываются сами при заказе, а в Telegram приходит «⚠️ Заканчивается».

## Заказы в Telegram


1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Добавьте бота в чат/группу продавцов, напишите там что-нибудь, узнайте `chat_id` (например, через `https://api.telegram.org/bot<TOKEN>/getUpdates`).
3. Укажите переменные (см. `shop/.env.example`). Без них заказ пишется в лог сервера — удобно для теста.

## Заказы в MAX

Можно вместо Telegram или вместе с ним: заказ придёт во все настроенные мессенджеры.
1. В MAX найдите **@MasterBot** → `/newbot` → получите токен. (Для бота организации может понадобиться верификация на [dev.max.ru](https://dev.max.ru).)
2. Впишите `MAX_BOT_TOKEN=…` в `shop/.env.local`.
3. Напишите своему боту что-нибудь в личку (или добавьте его **админом** в группу продавцов и напишите там).
4. `npm run max:setup` — покажет строку `MAX_USER_ID=…` (личка) или `MAX_CHAT_ID=…` (группа). Впишите её в `.env.local` и в Vercel.
5. `npm run max:setup -- test` — придёт тестовое сообщение.

Если один мессенджер недоступен, заказ всё равно уйдёт в другой. Покупатель видит ошибку, только если заказ не дошёл никуда (и нет Google Таблицы, куда он тоже пишется).

## Авито

- **Кнопка «Купить на Авито»** — заполните `avitoUrl` у товара.
- **Помощник объявлений** — вкладка «Авито» в студии: готовые заголовок, описание, цена, фото → копировать и вставить.
- **Автозагрузка** — сайт отдаёт фид `https://ваш-сайт/avito.xml`. Его указывают в кабинете Авито → Автозагрузка (нужен тариф Авито). Перед включением сверьте категории в `shop/src/avito.config.ts` с шаблоном Авито. В фид попадают только товары с настоящими фото.

## Публикация в интернете (Vercel, бесплатно)

1. Залить проект на GitHub.
2. [vercel.com](https://vercel.com) → New Project → выбрать репозиторий → **Root Directory: `shop`**.
3. В Settings → Environment Variables добавить переменные из `shop/.env.example`.
4. После добавления фото или правки товаров — `git push`, сайт обновится сам.
